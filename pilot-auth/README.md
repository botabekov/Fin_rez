# Fin_rez · пилот регистрации

Пилот регистрирует любой подтверждённый email, использует код из письма при первом входе и восстановлении, затем принимает email и пароль. Защищённый экран выполняет демонстрационный расчёт FIFO на трёх встроенных операциях. В интерфейсе пилота нет загрузки клиентских файлов.

## Размещение

GitHub хранит исходники. Cloudflare Worker проверяет вход и выполняет демонстрационный расчёт, D1 хранит сессии и суточные счётчики. Supabase Auth проверяет одноразовые коды и пароли, SMTP доставляет письма.

Для запуска нужны отдельный проект Supabase, отправитель SMTP и аккаунт Cloudflare. Секреты хранятся в настройках Worker и Supabase. GitHub, HTML приложения и логи не должны содержать пароль SMTP, ключ ограничения запросов или учётные данные пользователей.

- В Supabase включить вход по email и подтверждение адреса. В шаблонах **Magic Link** и **Reset Password** вывести `{{ .Token }}`. Срок одноразового кода — 10 минут. Установить минимальную длину пароля 12 символов.
- Подключить SMTP. При отправителе на бесплатном почтовом домене подтвердить адрес и отдельно проверить доставку на несколько независимых доменов.
- Создать D1 и применить `schema.sql`. В `wrangler.example.toml` указать ID D1 и публичный HTTPS-адрес Worker, соответствующий настройке `ORIGIN`.
- Передать в Worker `SUPABASE_URL`, `SUPABASE_KEY` проекта, случайный `RATE_KEY` длиной не менее 32 символов и проверенный адрес владельца для `ADMIN_EMAIL`. Для Auth используется ключ API с обычными правами, без `service_role`. Адрес владельца должен быть подтверждён тем же сценарием регистрации.

## Приёмка

- Проверить доставку кода к новому адресу, отказ для неверного и просроченного кода, отказ при повторном использовании и при несовпадении паролей.
- Проверить прямой доступ к сайту и расчёту до входа, в промежутке между кодом и заданием пароля, после входа и после выхода.
- Сбросить пароль через второй код. Старый пароль и прежние сессии должны перестать действовать.
- Сверить демонстрационный расчёт. Продажа 12 бумаг за 1 800 USD даёт себестоимость 1 240 USD и прибыль 560 USD. Повторный расчёт в сохранённой HTML-странице требует обращения к серверу с действующей сессией.
- Войти как обычный пользователь и как администратор. Счётчики регистраций, входов, восстановлений и расчётов доступны только администратору. Метрики не содержат идентификаторов пользователей или операций.

Локальная проверка сценариев с имитацией почтового сервиса и SQLite выполняется командой `node --test access.test.mjs pilot.test.mjs`. Доставка почты и запуск в облаке требуют отдельных проверок.

Перенос основной версии Fin_rez, её Excel-выгрузок и обработки клиентских отчётов в пилот не входит. Текущий публичный адрес GitHub Pages — отдельная публикация.
