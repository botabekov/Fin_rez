# PDF Editor Pro — MVP

Статический PDF-редактор, размещённый на GitHub Pages:

https://botabekov.github.io/Fin_rez/pdf-editor/

## Возможности
- Загрузка локального PDF, просмотр страниц и миниатюр.
- Выбор и редактирование распознанных текстовых фрагментов двойным кликом.
- Добавление и перемещение текстовых блоков.
- Создание таблиц, редактирование ячеек, добавление строк/столбцов.
- Изменение размера и позиции объектов через панель свойств.
- Отмена/повтор действий; локальный черновик в IndexedDB/localStorage.
- Экспорт изменённого PDF через pdf-lib.

## Ограничения и безопасность
Это **прототип**, а не полнофункциональный Acrobat. Замена/удаление существующего текста выполняется визуальным перекрытием области. Исходное содержимое PDF при этом **может оставаться извлекаемым из файла**. Не используйте такой экспорт для удаления персональных данных, коммерческих тайн и иной конфиденциальной информации.

Существующие PDF-таблицы не преобразуются автоматически в таблицы с ячейками: можно редактировать распознанные текстовые фрагменты, а новые таблицы добавлять поверх документа.

Текст новых объектов на экспортируемой странице встраивается как изображение для поддержки кириллицы; его нельзя искать как обычный текст. Сложные PDF (сканы, повороты страниц, нестандартные шрифты, подписи, сложные вложенные объекты) могут отображаться или экспортироваться с ограничениями. Рекомендуется проверить результат в Adobe Acrobat и других просмотрщиках.

Оригинальный документ не отправляется на сервер приложения: обработка выполняется в браузере. Для загрузки PDF-библиотек необходим интернет-доступ.

## Как пользоваться
1. Откройте ссылку на GitHub Pages.
2. Загрузите PDF либо откройте демо-документ.
3. Дважды нажмите на фрагмент текста, чтобы изменить его; используйте панель свойств.
4. Добавьте текст или таблицу, при необходимости переместите объект.
5. Нажмите «Скачать PDF».
6. Для продолжения после перезагрузки нажмите «Черновик» в верхней панели.

## Технологии
PDF.js 3.11.174, pdf-lib 1.17.1, HTML/CSS/JavaScript.

Для настоящего удаления содержимого и редактирования исходных таблиц потребуется отдельный PDF editing engine (например, MuPDF/PyMuPDF) с серверной/локальной обработкой и тестированием по типам PDF.
